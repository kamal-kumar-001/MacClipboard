Designed for Speed & Focus

Built from the ground up to keep you in the zone while writing code, drafting emails, or organizing notes.

Context-Aware Caret Anchoring

Unlike traditional menubar utilities that hide in the top corner, MacClipboard pops up directly next to your text insertion point with a native pointer notch.

Android-Style One-Key Paste

Press a single number key — 1 through 9, or 0 — to instantly paste that entry into your active editor without touching any modifier keys.

Instant Real-Time Search

Start typing the moment the popover opens. Real-time filtering quickly narrows down text, URLs, and code snippets across your history.

Click to Auto-Paste

Clicking any entry restores focus to your previous window and automatically executes a paste command, making mouse and trackpad interactions effortless.

100% Private & Offline

No telemetry, no background servers, and no cloud syncing. All clipboard history is stored exclusively in your macOS Application Support folder.

Native Swift & Ultra Lightweight

Written natively in Swift with SwiftUI. Consumes under 25 MB of memory and zero CPU cycles when idle. Starts instantly and launches at login.

Download & Installation

Get up and running in less than 30 seconds.

📦 Prebuilt Installer (.DMG)

Download the latest release and drag it into your Applications folder.

Download MacClipboard.dmg (~513 KB)
First Launch Note: Open the app from Finder, then choose Open. If blocked, open System Settings > Privacy & Security and select Open Anyway.

🛠️ Build from Source

Clone the repository and compile natively using Xcode Command Line Tools.

git clone https://github.com/kamal-kumar-001/MacClipboard.git && cd MacClipboard && ./Scripts/build-app.sh
Developer Note: Uses Swift Package Manager when full Xcode is selected, and swiftc directly when using Command Line Tools.

⚙️ Essential Setup (After Downloading)

Follow these two quick steps to enable caret-anchored pasting and automatic startup on your Mac.

🔐 Accessibility Permission
Required

Required by macOS so MacClipboard can detect your active text insertion caret across other apps (VS Code, Xcode, Notes, TextEdit, Browsers) and simulate ⌘V to paste at your cursor.

  • 1 Open System Settings on your Mac.
  • 2 Navigate to Privacy & Security → Accessibility.
  • 3 Toggle MacClipboard ON (or click + and select MacClipboard.app from Applications).
🚀 Start Automatically at Login
Recommended

Keeps MacClipboard running quietly in the background so Command-Option-V is always ready to use immediately whenever you log into your Mac.

  • 1 Open System Settings → General.
  • 2 Click on Login Items & Extensions (or Login Items).
  • 3 Under Open at Login, click the + button.
  • 4 Choose MacClipboard from your Applications folder and click Open.
